We want to add a feature to build the topology of the network in map. For that we are going to use DHCP Server, MAC Adress table, neighbor discovery, ARP Tables (and more?) to figure out connection between the devices. there are virtual and physical connection, but every connection has simply one type that contains the type and the speed (BASE-T 100M, 1G, 10G, etc, DAC 1G, DAC 10G, etc, Fiber MMF 1G, etc). The connection type we can read out of the interface information. There a suggestion of connection that are then manually converted by the user into conneciton that are then also displayed on the map. 
This has it's own menu entry. The first page will display the graph with circles and the names of the hosts and the conenction. Also all the hosts in one location are displayed togheter surounded with a gestrichelter circle. We can click on host, which will display more information on the side panel, from there we can click to see more. 
By default it will only display mikrotik routers, but we can select in the filters to also display hosts of one or multiple locations (and some more filter options). We can zoom and move around in that. 
the second tab contains a table paginatated with the connection that can be edited. 
the connection suggestions are in another tab these can then be made connections. 
The scanning of all that information on the mikrotik is done by a background tasks, that is triggered manually or in an programmable interval (defaults to every 14 days). It will then scan one router at a time. What it is doing and how many routers are still to be done are dispalyed in the same tab, where the task can be started. The task can be started for all, all for a location or a single router. 
there is an additional tab with network interfaces. These are identified network interfaces extracted from the information of the router. It automatically maps them to servers (windows or linux servers) by the mac address.
